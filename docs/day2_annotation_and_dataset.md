# 第 2 天：数据标注与训练数据准备

目标：理解 OCR 训练数据为什么分检测和识别两套，并准备好可训练的数据模板。

## 1. 检测和识别是两件事

### 文本检测

检测模型输入整张图，输出文字区域坐标。

适合解决：

- 漏检文字。
- 框偏了。
- 多行文字被框成一块。
- 低清、特殊字体、特殊场景文字检测不出来。

检测标签核心是：

```text
图片路径 + 文本框四点坐标 + 框内文字
```

### 文本识别

识别模型输入裁剪好的文本行图片，输出文字内容。

适合解决：

- 框是准的，但文字识别错。
- 业务专业词、型号、批号识别差。
- 特殊字符识别差。
- 固定字体、固定设备画面需要更高准确率。

识别标签核心是：

```text
裁剪图路径 + 文字内容
```

## 2. 是否一定要标注数据

如果你要训练，答案基本是：要。

可以不训练的情况：

- 默认 PP-OCRv5 对你的图片效果已经足够好。
- 只是做一个 Demo 或内部工具。

需要标注的情况：

- 你的图片领域很固定，并且默认模型不稳定。
- 你要提升某类字符、票据、表单、设备屏幕、工业喷码的识别率。
- 你要评估模型效果，需要验证集。

## 3. 推荐标注工具：PPOCRLabel

PPOCRLabel 是 PaddleOCR 官方生态里常用的 OCR 标注工具，适合生成检测和识别相关数据。

常见流程：

1. 安装 PaddleOCR 相关环境。
2. 打开 PPOCRLabel。
3. 导入图片目录。
4. 使用自动标注生成初稿。
5. 人工修正文本框和文字。
6. 导出训练数据。

建议：

- 先标 20 张图练手。
- 不要一上来标 1000 张，先让训练命令跑通。
- 每张图标完后抽查坐标和文本内容。

## 4. 检测数据格式

模板见：

```text
datasets/det_dataset_template/train.txt
datasets/det_dataset_template/val.txt
```

示例：

```text
images/demo_001.jpg	[{"transcription":"示例文字","points":[[10,20],[200,20],[200,60],[10,60]]}]
```

字段解释：

- `images/demo_001.jpg`：相对 `data_dir` 的图片路径。
- `transcription`：框内文字。
- `points`：文本框四个角点。

如果一张图有多个文本框，JSON 数组里放多个对象：

```text
images/demo_002.jpg	[{"transcription":"第一行","points":[[10,20],[120,20],[120,50],[10,50]]},{"transcription":"第二行","points":[[10,70],[120,70],[120,100],[10,100]]}]
```

## 5. 识别数据格式

模板见：

```text
datasets/rec_dataset_template/train.txt
datasets/rec_dataset_template/val.txt
datasets/rec_dataset_template/dict.txt
```

示例：

```text
images/demo_001.jpg	示例文字
```

这里的 `images/demo_001.jpg` 不是原始大图，而应该是裁剪好的文本行图片。

## 6. 字典文件

识别训练必须重视字典。

字典示例：

```text
示
例
文
字
验
证
```

规则：

- 一行一个字符。
- 标签里出现的字符都必须在字典里。
- 如果有英文字母、数字、符号，也要加入。
- 训练、评估、导出、推理最好使用同一份字典。

常见错误：

```text
KeyError / character not found / acc 一直很低
```

多数时候是标签字符和字典不匹配。

可以用本仓库的检查脚本先扫一遍：

```powershell
python tools\check_rec_label_dict.py `
  --label-file datasets\rec_dataset_template\train.txt `
  --dict-file datasets\rec_dataset_template\dict.txt `
  --use-space-char `
  --max-text-length 25
```

如果输出 `Missing chars: none`，说明标签字符至少都被字典覆盖了。

## 7. 数据拆分

最小可行：

```text
train:val = 8:2
```

如果数据很少：

```text
训练集 80 张
验证集 20 张
```

验证集不要全是简单图片，要覆盖：

- 模糊图。
- 倾斜图。
- 复杂背景图。
- 常见业务字段。
- 容易识别错的字符。

## 8. 标注质量的坑

### 框太松

文本框包含太多背景，会影响检测和识别裁剪。

### 框太紧

切掉文字边缘，识别模型容易学错。

### 漏标

检测训练时，图片里有文字但没标，模型会被误导。

### 文字内容错

识别训练对标签极其敏感。标签错，模型会认真学习错误答案。

### 特殊字符漏进字典

比如：

```text
- / . : # % ℃ μ Ω
```

业务型号、单位、序列号里经常出现。

### 中英文空格

如果标签里有空格，要确认配置里开启 `use_space_char`，并且推理时也保持一致。

## 9. 第二天验收标准

你完成这些就算第 2 天成功：

- 知道检测和识别数据格式不同。
- 能用 PPOCRLabel 标出文本框。
- 能导出或整理检测训练标签。
- 能裁剪文本行，整理识别训练标签。
- 能检查标签字符是否都在字典里。
